# 타로 카드 상징 탐험

카드를 가운데 놓고, **테마**(소지품·의복·자연·자세·기호·인물·장소·동물·식물·색)를 눌러 카드 속 물건들의 의미를 살펴보는 학습용 사이트입니다.

- 78장 전체 카드, 카드당 5~10개의 상징(총 548개)
- 테마 버튼 → 카드 위에 해당 물건이 번호 핀으로 표시 → 핀/목록 클릭 시 의미 표시
- 키보드 ← → 및 모바일 스와이프로 카드 넘기기

교재: *The Big Book of Tarot Meanings* (Sam Magdaleno)

배포: GitHub Pages (`index.html`)
